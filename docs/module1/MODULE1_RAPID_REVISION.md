# CSE2101 Module 1 — Rapid Revision Sheets

## 30-minute revision
O/Ω/Θ; row-major vs column-major; sparse triplet; Horner form; SLL head/next/NULL; circular last→head; DLL prev/next.

## 1-hour revision
Review every P1/P2 question in the matrix and state its trigger, invariant and complexity.

## 3-hour revision
Attempt one authentic question from each master pattern, then revisit missed subpatterns.

## Night-before revision
Memorize formulas/invariants. For linked lists, remember SAVE next → RECONNECT → MOVE.

## Zero-mistake checklist
- subtract lower bounds;
- state element width if omitted;
- repair circular boundary links;
- update both DLL directions;
- do not advance prev after deleting a matching SLL node;
- include traversal/search cost in total complexity.
